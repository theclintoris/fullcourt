# FullCourt 1.4.0 — Personal Player Records

- **Search more than 5,000 players** under **Records → Player search**. Search by name and choose a player to open their profile.
- **Five record views** cover regular-season game highs, playoff game highs, season highs, full playoff run highs, and career totals split between regular season and playoffs.
- **Traditional and advanced stats** include points, rebounds, assists, steals, blocks, turnovers, field goals, threes, free throws, shooting percentages, Game Score, true shooting, effective field goal percentage, and season PER and BPM.
- **Offline archive** includes available NBA and BAA box scores through 16 November 2026 and completed playoff runs through 2025–26.

## Windows x64 downloads

| Option | File |
| --- | --- |
| Portable EXE | `FullCourt-Portable-1.4.0.exe` |
| Installer | `FullCourt-Setup-1.4.0.exe` |
| Portable folder ZIP | `FullCourt-1.4.0-win-x64.zip` |

The portable EXE runs without installation. For the ZIP, extract the folder and run `FullCourt.exe`. The Windows builds are unsigned, so SmartScreen may prompt on first launch. SHA-256 checksums are included.
