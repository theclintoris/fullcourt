# FullCourt 1.3.0 — Franchise Records

- **Franchise records for all 30 teams** — find any team by its current or former name under **Records → Teams → Franchise records**. Browse all-time regular-season and playoff win–loss records, championship seasons, single-game highs, streaks, and season-by-season results and stats.
- **Complete season histories through 2025–26** — the bundled archive includes 1,723 team seasons. The current season’s win–loss record appears when ESPN standings are available.
- **Visual refresh** — updated navigation, a redesigned Record Book and team pages, and a new Scores spotlight treatment.

## Windows x64 downloads

| Option | File |
| --- | --- |
| Portable EXE | `FullCourt-Portable-1.3.0.exe` |
| Installer | `FullCourt-Setup-1.3.0.exe` |
| Portable folder ZIP | `FullCourt-1.3.0-win-x64.zip` |

The portable EXE runs without installation. For the ZIP, extract the folder and run `FullCourt.exe`. The Windows builds are unsigned, so SmartScreen may prompt on first launch. SHA-256 checksums are included.
